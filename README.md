# Personal Portfolio Website

**Live website:** [https://barderus.github.io/portfolio-website/](https://barderus.github.io/portfolio-website/)

A personal portfolio website developed using **React, Vite, and Framer Motion** to showcase my professional experience, software development projects, data science work, academic research, and other activities.

The website brings together my technical and professional background in one place, providing an interactive way to explore my projects, experiences, and interests.

## Features

- **Multi-Page Navigation:** Dedicated sections for professional experience, projects, research, teaching, and personal activities.
- **Responsive Interface:** Layouts designed for different screen sizes.
- **Interactive Components:** Animated transitions, project cards, and image galleries.
- **Project Showcase:** Summaries of technical and research projects with links to repositories and related resources.
- **Professional Background:** Information about education, work experience, teaching, and leadership activities.
